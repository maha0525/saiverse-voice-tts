# Irodori-TTS 専用の Python 環境 (Windows / Linux、NVIDIA GPU) に入れるパッケージ。
#
# アドオンカタログの導入で、addon.json の setup.steps の pip_install
# (env: irodori, os: windows / linux) がこのファイルを入れる。step の作業
# フォルダはアドオンのフォルダなので、./external/Irodori-TTS は直前の git_clone の
# step が取得した Irodori-TTS (commit 89f9d8fbd4d51ea019867ee1197725ede1df13c5)。
# Irodori-TTS 自身の依存 (transformers>=5、peft>=0.18、gradio>=5 等) は、その
# pyproject.toml から入る。GPT-SoVITS とも本体の venv とも両立しないので、専用環境に入れる。
#
# 下限の方針: 脆弱性の修正版があるパッケージはその修正版を下限にし、それ以外は
# 2026-01-01 までに出た版 (既存の環境が既に満たしている版) を下限にする。下限を
# 上げたら addon.json の setup_version も上げる — アドオンの更新で pip install -r が
# 再実行され、下限を満たさないパッケージが引き上げられる。Irodori-TTS 自身の依存の
# 下限は、その pyproject.toml が持つ。
#
# torch / torchaudio は CUDA 12.8 版に固定 (本体 venv で合成実績のある組)。
# Irodori-TTS の pyproject.toml は torchcodec を <0.11 に縛っている (torchcodec 0.10 は
# torch 2.10 向け)。torch 2.11 の torchaudio.load が torchcodec を読めないときは、
# Irodori-TTS の _load_audio が soundfile に切り替えて参照音声を読む。
--extra-index-url https://download.pytorch.org/whl/cu128

torchaudio==2.11.0+cu128
