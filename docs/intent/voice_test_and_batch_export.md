# Intent: ペルソナ別の音声テスト再生・WAV 単発保存・複数テキスト一括 ZIP 出力

**ステータス**: 検証待ち（実装・全テスト緑・まはー実機確認済み、PR レビュー待ち／SAIVerse v0.3.35 リリース後にカタログ登録）

## これは何か

アドオン管理画面の「ペルソナ別設定」直下に音声テスト・ファイル出力パネル (`ui/PersonaPanel.tsx`) を追加し、選んだペルソナの声設定（エンジン・Voice ID・参照音声・話速・読み方辞書）を使って:

1. 任意のテキストをその場で合成してブラウザでテスト再生する
2. 合成した音声を 16-bit PCM WAV ファイルとして保存する
3. 複数テキスト（JSON 配列または 1 行 1 セリフ、`.json` / `.txt` ファイル読み込み対応）を順次合成し、各 WAV と対応表 `manifest.json` をまとめた ZIP ファイルとして保存する

ことができる機能。あわせて、外部スクリプト等から 1 リクエストで ZIP を取得できる `POST /synthesize-batch` API も提供する。

## 不変条件

1. **ペルソナの世界・記憶・チャット履歴を一切汚さない**: テスト合成・一括合成は LLM・SAIMemory・BuildingHistory・吹き出しメタデータ・`audio_stream`・サーバー側スピーカー再生・`outputs/` 保存ディレクトリのいずれにも触れない。
2. **`auto_speak` が OFF のペルソナでも使える**: 自動発話を切っているペルソナでも声設定の確認や素材生成を行える（ただしアドオン自体が無効なときは拒否する）。
3. **既存ワーカーと GPU 推論を直列化する**: `playback_worker.synthesize_wav()` は既存の `_TTSWorker._queue` に `_DirectJob` を並べて処理し、通常会話の TTS とローカル GPU エンジンを同時に走らせない。
4. **設定変更直後の反映**: パネルは合成 API を呼ぶ前に SAIVerse 本体の `flushPendingSaves()` を待ち、直前に編集した Voice ID や話速が保存された状態で合成する。
5. **ファイル名の安全性と英語文の誤爆防止**: 一括入力はカンマ区切りを採らず JSON 配列（文字列配列 / `{"filename", "text", "persona_id"?}`）と改行区切り（1 行 1 セリフ）を採用する。ファイル名はパストラバーサル・禁止文字・Windows 予約デバイス名を無害化し、重複名は連番を振って上書きを防ぐ。
6. **長時間バッチの耐性と制御性**: UI 側の一括合成は 1 件ずつ `POST /synthesize` を呼び、進捗表示・途中中止・個別試聴・クライアント側 ZIP 生成（UTF-8 フラグ付き STORE + CRC-32）を行う。

## 本体とのバージョン要件

- `ui/PersonaPanel.tsx` の表示には SAIVerse 本体の `ADDON_PERSONA_PANELS` 拡張（**v0.3.35 以降**）が必要。
- アドオンカタログ (`saiverse-addon-registry`) へ v0.7.0 を載せる際は `min_saiverse_version: "0.3.35"` を指定する（v0.3.35 リリース後に登録）。
